Set up Start from this dashboard
  1. Upload the package, including .github/workflows/start-kaggle.yml and the notebook, to your GitHub repository.
  2. In GitHub Actions settings, add secret KAGGLE_API_TOKEN, variable KAGGLE_KERNEL_ID (username/notebook-slug), and variable DASHBOARD_URL (this site's origin).
  3. In Cloudflare Worker settings, set variable GITHUB_REPO (username/repository) and secret GITHUB_TOKEN (a repository-restricted token with Actions read/write permission).
  4. Enable the three PeakCut secrets in your private Kaggle notebook. Start submits a new batch run; it does not resume a browser session.

The presence of settings does not verify permissions or Kaggle quota. Startup logs show failures.

Stop processing requires the updated notebook. It stops PeakCut and finishes a batch run. For an interactive run, also stop its allocation in Kaggle. Scheduled posts need the worker and video files available at their due time.
